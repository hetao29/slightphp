SlightPHP\Config

解析 JSON 或 JSONC 配置，并可在进程内缓存解析结果。

公开属性

static $CACHE

公开方法

static getConfig($configFile, $zone = NULL)
读取配置或顶层区域。区域值为 null 或不存在时，回退到非 null 的 default 区域。 区域按对象属性读取；JSON 顶层数组和标量适合不指定区域时直接读取。
static parse($configFile)
按扩展名（不区分大小写）选择格式：.json 使用严格 JSON， .jsonc 额外支持 // 行注释及斜杠星号块注释；不再支持 .conf 等其他格式。 JSON 对象解码为 stdClass，数组和标量保留原类型；不支持尾随逗号。 启用缓存时按规范路径及格式复用进程内结果，不读写旧的序列化文件缓存。
