SlightPHP\Tpl

模板入口：变量分配、编译缓存管理及当前实例中的 PHP 执行环境。 处理流程为 render/display -> fetch -> Compiler::compileSource -> include。 6.7 起统一使用上下文自动转义，不提供模式切换接口。 编译结果包含静态块、属性和 JS 候选计划，最终编码取决于实际 Context。 默认分隔符下用 {* ... *} 编写单行或多行模板注释，编译时移除，内部标签不执行。 注释不能嵌套，未闭合抛出 InvalidArgumentException；literal 块内按原文输出。 变量表属于实例；模板目录、编译目录、分隔符及编译选项由所有实例共享。 同实例的 include 沿用变量和 Context；最外层 fetch 负责创建、完成及释放输出状态。 常驻服务通常按请求新建实例，本类不提供协程间的静态配置隔离。 模板会编译为 PHP，必须来自可信来源；上下文编码不将模板变成沙箱。 render/display/fetch 直接写入当前输出流，既不返回完整 HTML，也不缓存最终页面数据。

fetch($tpl)
必要时编译模板，并在当前实例作用域直接 include 编译文件。 源文件及编译文件必须分别位于模板目录及编译目录内；每级子目录均检查 realpath。 沿用源目录 CRC32 子目录布局及 .context.php 后缀。文件头校验编译格式、 分隔符及 JS 计划版本，避免重用不兼容的编译结果；不保存变量或最终 HTML。 嵌套 fetch 复用实例 Context，不要求子模板结束时回到文本状态；最外层才 finish。 无论正常结束或异常传播，最外层都释放 Context，模板变量表则继续保留。
redirect($url)
发送 Location 并立即结束 PHP 执行；默认通常是 302，最终状态受 PHP 响应环境影响。

SlightPHP\Tpl\Func

内置模板函数的静态实现，也可在应用 PHP 代码中直接调用。 编译器将对应标签映射到本类，对 include/part 单独生成输出调用， 保持父实例及真实上下文，普通返回值函数则由调用位置决定编码。 本类不导出旧的 tpl_function_* 全局函数，不维护共享模板变量或全局 Tpl 实例。

公开方法

static tostring($mixed)
将任意值转为可读文本，便于模板展示结构化调试信息。 返回原始 print_r 文本，不在函数内部编码；模板根据实际输出位置编码。
static part($path)
调用指定路径的控制器入口，保留模块直接输出，并追加其字符串返回值。 字符串（含 "0"）之外的返回值不作为 HTML 输出；函数本身返回 null。 直接调用不收集/管理输出缓冲，也不将父模板变量自动分配给模块创建的新 Tpl。 自动模式通过 Tpl 的专用 part 入口收集并跟踪该可信 HTML，模块仍负责内部编码。
static include($tpl, SlightPHP\Tpl $context)
用给定实例输出子模板，复用其变量表、Context 和当前渲染深度。 模板 include 标签由编译器提供当前实例；PHP 直接调用时必须显式传入。 已在渲染中的父实例会共享 Context；独立调用时 fetch 自行建立最外层渲染边界。

SlightPHP\Tpl\Modifier

内置修饰器集合，保留历史参数和返回行为。 编译器以被修饰值作为第一个参数调用；在 PHP 代码中也可直接使用静态方法。 模板先转换数据再按实际输出位置编码。escape 的输出 意图由 ModifierValue 传递给 Context，避免重复 HTML/URL 编码；raw 应放在链末尾。

公开方法

static raw($value)
返回原值，不执行编码。模板管道末尾使用 raw 表示最终结果是调用方负责的可信原文。 PHP 直接调用只返回数据本身，不会赋予字符串跨上下文的安全属性。
static tostring($mixed)
返回任意值的 print_r 文本，不自动添加 HTML 编码。
static tr($string, $zone = 'main')
使用 Language 的当前语言及词条回退规则翻译，不编码翻译结果。
static escape($string, $type = 'html')
手动 HTML 文本/带引号属性编码，或将输入作为一个 URL 组成部分编码。 仅 type 为小写 url 时使用 rawurlencode；其他类型沿用 HTML 分支，固定 UTF-8、 包含单双引号并替换无效字节。不检查 URL 协议，也不用于 JS/CSS 字符串编码。
static default($input, $default = '')
使用 PHP empty 语义选择缺省值，不只判断是否定义或是否为 null。 false、0、"0"、空字符串和空数组等都会落到缺省分支；不改变该历史兼容行为。
static version($string, $version = '1.0')
直接在原字符串末尾追加问号和版本文本，保留历史拼接方式。 不解析已有查询参数/片段，不校验 URL 协议，也不对结果做 HTML 编码。
